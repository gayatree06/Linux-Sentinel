# Stage 1 – Project Introduction

## 1.1 Project Title

**Linux Sentinel: A C++-Based System and Device Health Monitoring System**

## 1.2 Project Introduction

Linux Sentinel is an individual capstone project developed as part of the Wipro LSP & LDD 20-Day Training Program.

The project is designed as a Linux-based system and device health monitoring application. It uses a C++ command-line application to monitor system resources, interact with Linux system interfaces, demonstrate TCP/IP communication, and provide device management functionality.

A Linux character device driver is also implemented to demonstrate interaction between user space and kernel space.

## 1.3 Problem Statement

Linux systems and embedded computing environments require continuous monitoring of system resources and device health.

Without a unified monitoring application, users may need to access different Linux interfaces and commands to understand CPU usage, memory information, storage status, running processes, network communication, and device status.

Linux Sentinel addresses this requirement by providing a single command-line application for basic system and device health monitoring.

## 1.4 Project Objectives

The main objectives are:

- Monitor CPU information.
- Monitor memory information.
- Monitor storage information.
- Monitor running processes.
- Demonstrate Linux system programming concepts.
- Demonstrate TCP/IP client-server communication.
- Implement a Linux character device driver.
- Provide user-space interaction with the device driver.
- Maintain application logs.
- Apply C++ programming and software architecture concepts.
- Use Git for version control and project tracking.

## 1.5 Project Scope

The project covers:

- Linux-based system monitoring.
- C++ application development.
- Linux system calls and file descriptors.
- TCP/IP socket communication.
- Linux character device driver implementation.
- Device management.
- Application logging.
- Command-line user interaction.
- Git-based version control.
- Testing and documentation.

The project is developed as a prototype and does not depend on physical embedded hardware.

## 1.6 Expected Outcome

The expected outcome is a functional Linux command-line prototype that can:

- Display system health information.
- Display device status.
- Demonstrate TCP/IP networking.
- Maintain application logs.
- Interact with a Linux character device when the driver is available.
- Demonstrate concepts from the 20-day training program.

## 1.7 Application of the Project

Linux Sentinel can serve as a prototype for monitoring applications used in:

- Linux servers.
- Embedded Linux systems.
- IoT gateways.
- Industrial computers.
- Network appliances.
- System administration environments.
